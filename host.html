Set up your connection

  1. Open this page in a browser on your Mac. Download and open the disk image.
  2. Drag DeskRoamHost to Applications, then open it from Applications. The Host is Developer ID signed and notarized by Apple. You do not need to disable Gatekeeper.
  3. Grant Screen Recording to share the Mac display, and Accessibility for remote pointer, scrolling and keyboard input. Follow the Host's System Settings buttons. If macOS asks you to quit and reopen the Host, do so.
  4. Keep both devices on the same local network, or connect them through your own private Tailscale network. No public internet relay is provided.
  5. In DeskRoam on iPhone/iPad, choose Add Mac. Enter the address and pairing code shown by the Mac Host. Keep the pairing code private. Previously paired devices can reconnect using their stored credentials.

If the screen is visible but input does not work, check Accessibility for the installed Host. After replacing a build, macOS may require permission to be granted again.

Updates and troubleshooting

Updates are manual: quit the Host, download the newer release, and replace the app in Applications. Keep a copy of the previous version if you need to roll back. No automatic updater is provided.

The Host remains sandboxed and stores pairing credentials in Keychain. Session content travels directly between your devices using encrypted transport; the developer does not collect it.
